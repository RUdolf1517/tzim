  §7.3.5 (Variable-length arrays): a P descriptor consists of two 32-bit
  signed integer values; negative values have no defined meaning in the Standard.
  §5.2.3 (Thirty-two-bit integer): signed range is -2147483648 through
  +2147483647. Therefore valid non-negative P count/heap-offset values are
  exactly 0..=2147483647.

  1303
  1304	CFITSIO provides easy-to-use support for reading and writing data in
  1305	variable length fields of a binary table. The variable length columns
  1306	have TFORMn keyword values of the form `1Pt(len)' or `1Qt(len)' where `t'
  1307	is the data type code (e.g., I, J, E, D, etc.) and `len' is an integer
  1308	specifying the maximum length of the vector in the table.  The 'P' type
  1309	variable length columns use 32-bit array length and byte offset values, whereas
  1310	the 'Q' type columns use 64-bit values, which may be required when dealing
  1311	with large arrays.  CFITSIO supports a local convention that interprets
  1312	the 'P' type descriptors as unsigned 32-bit integers, which provides
  1313	a factor of 2 greater range for the array length or heap address than
  1314	is possible with 32-bit 'signed' integers.  Note, however, that other software
  1315	packages may not support this convention, and may be unable to read thees
  1316	extended range variable length records.
